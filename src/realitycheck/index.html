Help & Shortcuts

How to use

  • Pick a mode, then paste text, upload media, or fetch a URL before analyzing.

Best results

  • Use direct media URLs and clean source material so fallback handling stays minimal.

Shortcuts

  • Enter submits the direct image and video URL fields.

Caveats

These scores are signals, not proof. Check sources and context before acting on them.

Privacy

Text, image, and video analysis stay in your browser. URL mode asks the local server to fetch page text first.

Local only

The analysis models run on this device after loading. The local proxy is only used to fetch URL content.
